# Assignment-4-Implementing-Control-Structures
How to Run

# C++ (schedule.cpp):

Open terminal in the folder where the file is saved.

Type:
```
g++ -std=c++11 schedule.cpp -o schedule
./schedule
```
Enter employee names and shifts when asked.

The final schedule will appear on the screen.

# Python (schedule.py):

Open terminal in the folder where the file is saved.

```
python3 schedule.py
```

Enter employee names and shifts when asked.

The final schedule will appear on the screen.
